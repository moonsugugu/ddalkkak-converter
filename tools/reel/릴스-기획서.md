# 딸깍변환 릴스 기획서

작성일: 2026-10-24 · 상태: 초안, 사용자 검토 대기

2026-10-25 참고 릴스 검토: [참고앱 기능 비교](참고앱-기능비교.md)에 현재 변환 범위와 확장 후보를 정리했다. 아래 36초 시간표는 최초 초안이며, 영상·음성 등을 더 보여주는 수정 범위는 아직 확정하지 않았다. 새로 제안한 기능을 구현 완료 기능으로 영상에 넣지 않는다.

## 목적과 대상

한글 문서·PDF·사진을 자주 다루는 선생님과 Windows 사용자에게 딸깍변환의 사용 방식을 보여준다. 핵심은 **파일 선택 → F12 → 형식 클릭 → 미리보기 → 저장**이다. 키를 누르는 것만으로 저장까지 끝난다고 표현하지 않는다.

한 줄 콘셉트: **학부모에게 보낼 자료를 준비할 때, 파일을 고르고 F12로 딸깍.**

실제 앱: 딸깍변환 3.1.0, Windows 트레이 상주 도구. 앱 소스 기준은 GitHub `moonsugugu/ddalkkak-converter`의 `v3.1.0`이다.

## 규격과 톤

- 약 36초, 세로 1080×1920, MP4와 커버 JPG. 내레이션 없이 읽히는 한국어 자막과 동작 효과음을 기본으로 한다.
- PC용 앱이므로 가로 Windows 화면을 노트북 틀 안에 펼쳐 맥락을 먼저 보여주고 원형 메뉴·미리보기를 확대한다. 모바일 앱처럼 다시 그리지 않는다.
- 앱의 파스텔 클레이 톤: 배경 연보라 `#f3effa`, 밝은 크림, 민트 `#c9f1e7`; 강조 보라 `#7561cf`, 글자 짙은 보라 `#292344`.
- `style: soft`, `title_font: gothic`. 굵은 고딕 제목, 부드러운 그림자, 둥근 형태. 장식보다 실제 메뉴와 결과 화면을 크게 둔다.
- 첫 프레임에 선택된 파일과 열리는 원형 메뉴를 보여준다. 로고 인트로는 넣지 않는다.
- 자막은 한 번에 한 내용만 표시한다. 인스타 UI가 가리는 아래 20%와 오른쪽 가장자리를 피한다.

## 이야기와 대본

상황은 **체험학습 안내 자료를 학부모에게 보낼 준비**로 이어진다. 시연용 한글 안내문, 사진이 든 한글 문서, 기울어진 문서 사진, 5쪽 PDF를 사용한다. 실제 학생·학부모 정보는 넣지 않는다.

| 시간 | 화면과 동작 | 자막 | 편집·소리 |
|---|---|---|---|
| 0–3초 | 선택된 한글 파일 근처에 실제 원형 메뉴가 펼쳐지고 커서가 PNG로 이동한다. 결과는 아직 전부 공개하지 않는다. | 파일 고르고 / F12 딸깍 | 첫 프레임부터 앱 화면. F12 키 표시와 입력 시각을 맞추고 PNG 클릭에 작은 클릭음. |
| 3–8초 | 가로 탐색기 맥락으로 돌아가 안내문 선택 → F12 → PNG 클릭을 자연스럽게 보여준다. | 한글 파일을 / PNG로 바꾸고 | 확대는 원형 메뉴 쪽으로 한 번. 실제 변환 대기 중 불필요한 구간만 줄인다. |
| 8–12초 | 원본·결과 미리보기에서 문서가 같은 내용인지 비교하고 ‘이대로 저장’을 누른다. | 미리보기 확인하고 / 저장하면 끝. | 결과 영역을 크게 보여주고 저장에 짧은 성공음. |
| 12–17초 | 사진이 든 한글 문서에서 용량 줄이기를 선택한다. 실제 전후 미리보기와 용량을 보여준다. | 한글 속 사진 용량도 / 줄여주고요. | 실제 용량 부분에만 작은 강조 표시. 검증 자료의 61.5%는 시연 참고치이며 새 촬영에서 나온 실제 값만 쓴다. |
| 17–22초 | 기울어진 인쇄 문서 사진 → 스캔 보정 → 보정된 결과 미리보기. | 기울어진 문서 사진도 / 반듯하게. | 원본·결과에 각 1회 집중. 효과로 사진을 보정한 척하지 않고 앱의 실제 출력을 사용한다. |
| 22–28초 | 5쪽 PDF에서 PDF 분리 → 1쪽씩 지정 → 실제 5개 결과를 확인한다. | 여러 쪽 PDF는 / 한 장씩 나눠요. | 쪽수 입력과 분리 파일 이름을 읽을 시간을 준다. 생성된 파일 개수는 실제 결과와 일치해야 한다. |
| 28–32초 | 안내문 PNG와 원본 한글이 함께 보이는 결과 폴더. 실제 변환 결과를 열어 확인한다. 이 장면이 최종 결과 강조다. | 원본은 그대로. / 결과는 새 폴더에. | 결과 파일로 줌. 자막을 화면 가운데 한 번 크게 표시하고 작게 성공음. |
| 32–36초 | 딸깍변환 아이콘, 앱 이름과 사용 흐름을 차분하게 표시한다. | 댓글에 ‘딸깍’ 남겨주시면 / 다운링크 보내드릴게요. | 아이콘 튀기기·문구 깜빡임 없이 작은 마무리음. `made by 문수네집 · moonsunezip.com` 표시. |

위쪽 제목은 첫 장면의 **파일 변환 / F12로 딸깍**에만 크게 사용한다. 메뉴·미리보기 확대 장면에서는 숨겨 앱 화면 공간을 확보한다. 기능 번호를 붙이는 목록식 편집이나 빠른 기능 몽타주는 사용하지 않는다.

## 커버와 CTA

- 커버 문구: **파일 고르고 / F12 딸깍**. 작은 보조 문구: **한글 · PDF · 사진 변환**.
- 실제 원형 메뉴와 F12 키 모양을 중심에 배치한다. 휴대폰 화면이나 가짜 앱 UI는 만들지 않는다.
- 1080×1920에서 위·아래 배경 여백은 각각 약 16%, 주요 내용은 중앙 68% 안에 둔다.
- 기본 CTA: **댓글에 ‘딸깍’ 남겨주시면 다운링크 보내드릴게요.** 문구만 제작하며 댓글 답장이나 DM 전송을 실행하지 않는다.
- 다운로드 위치: https://github.com/moonsugugu/ddalkkak-converter/releases/latest
- 영상에 넣지 않는 영상·음성 변환, OCR, 단축키 변경, 즐겨찾기와 튜토리얼은 필요한 경우 게시물 캡션에서 짧게 보충한다.

## 실제 기능과 연출의 구분

- 실제로 확인한 기능: 설치본의 탐색기·바탕 화면 선택 → F12 → PNG → 미리보기 → 저장, HWP 사진 압축과 원본 보존, 스캔 보정, PDF 자동 분리. 근거는 README와 기존 검증 보고서이다.
- 새 영상의 시연 파일·탐색기 위치·커서 이동·노트북 틀·F12 키 그래픽·확대는 설명을 위한 연출이다. 앱 UI와 변환 결과 자체는 실제 앱에서 가져온다.
- 한글 네이티브 변환에는 한컴오피스 한글이 필요하다. 영상은 한글 설치 PC에서 촬영하고 게시물 캡션에 이 조건을 적는다.
- ‘몇 초 만에’, ‘항상 몇 % 절감’, ‘완벽하게 보정’ 같은 미확인 수치·보장 문구는 사용하지 않는다.
- 변환 대기 시간을 줄이면 기다리는 구간만 편집한다. 클릭이나 저장이 실제보다 자동으로 된 것처럼 이어 붙이지 않는다.
- 기존 검증 캡처 중에는 작업 화면이 섞인 자료가 있어 완성 영상에 그대로 사용하지 않는다. 신규 촬영은 시연 전용 파일과 확인된 앱 창만 담는다.

## 제작에 필요한 자료와 확인 사항

기획 확정 뒤 다음 자료를 준비하고 촬영한다.

1. 개인정보가 없는 체험학습 안내문 HWP, 사진을 포함한 HWP, 기울어진 문서 JPG, 5쪽 PDF.
2. 별도 시연 설정과 폴더. 실제 사용자 설정·사용 횟수·문서·바탕 화면 파일은 바꾸지 않는다.
3. Tkinter 기반 실제 앱 창과 탐색기 동작 녹화. Electron 전용 `capturePage`를 이 앱에 적용하지 않는다. 캡처 전 창 제목·프로세스와 화면을 대조해 다른 앱이 찍히지 않게 한다.
4. 실제 PNG 미리보기, 압축 용량, 스캔 보정 결과, PDF 분리 파일 수를 촬영 당일 다시 확인한다.
5. 클릭·키 입력 시각을 기록해 효과음과 키 그래픽을 맞춘다. 같은 동작의 연속 컷에는 전환음을 생략한다.

최종 전달: `output/딸깍변환-릴스.mp4`, `output/딸깍변환-커버.jpg`. 제작 시 사용한 설정은 `tools/reel/`에, 시연 녹화와 프레임은 Git에서 제외한 `output/`에 둔다. 게시물용 기능 캡처는 `홍보글/캡처/`에 정리한다.

## 제작 전후 확인

현재 단계는 기획 검토다. 사용자가 이 구성을 확정하고 제작을 요청하면 녹화·에셋·렌더링을 진행한다. 그 전에 제작용 캡처나 프레임 생성은 하지 않는다.

제작 후에는 1080×1920·길이·오디오 트랙, 자막 읽기 속도·잘림·네모 글자, 실제 동작과 효과음, 개인 작업 화면 노출 여부를 확인한다. 영상 전체를 재생하고 휴대폰 피드 크기와 무음에서도 사용 순서가 전달되는지 점검한다. 재생 검증이 불가능하면 확인한 범위를 구분해 전달한다.

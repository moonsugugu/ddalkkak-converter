# 참고 릴스와 딸깍변환 기능 비교

확인일: 2026-10-25. 비교·기능 제안 단계이며 아래 추가 후보를 구현 완료했다고 의미하지 않는다.

이후 사용자 지정 범위에 따라 3.2.0에서 사진 입력·사진 편집·PDF 편집과 추가 형식을 구현했다. 현재 구현 범위는 프로젝트 README의 ‘3.2 사진·PDF 편집과 추가 형식’을 따른다. 아래 비교표와 숫자는 3.1.0을 검토하던 당시 기록이며, 영상·음성 편집 확대 등 나머지 후보까지 구현됐다는 뜻은 아니다.

Tangerine 공식 소개는 **275개 변환 경로, 26개 파일 도구, 6개 파일 동작**을 안내한다. 275는 서로 다른 파일 형식의 개수가 아니라 입력→출력의 변환 경로다. 공식 소개의 형식 목록과 실제 품질을 같은 것으로 간주하지 않는다.

## 비교 당시 딸깍변환 3.1.0 기능

| 분야 | 코드와 설명서에서 확인한 범위 |
|---|---|
| 한글·Office | HWP/HWPX, Word, Excel, PPT 입력. 문서 종류에 따라 PDF·이미지·텍스트·다른 문서 형식 출력. 네이티브 변환에는 설치된 한글·Office 필요 |

### 변환 수 집계의 정확한 의미

3.1.0의 `SUPPORTED`와 `targets()`를 읽으면 입력 확장자 34개, 기본 변환 경로 226개다. `compress`·`images` 도구는 제외했고 `.jpeg`와 `.tif` 별칭을 각각 계산했다. 이 두 별칭을 제외하면 32개 입력 확장자와 210개 경로다.

이것은 **메뉴에 정의된 경로 수**다. 226개 경로 모두가 모든 PC·문서에서 성공했다고 검증한 수가 아니다. 한글·Office 설치, 코덱과 원본 내용에 따라 실행 조건과 결과가 달라진다. 집계 방식이 다른 경쟁 앱과 숫자만으로 우열을 판단하지 않는다. 릴스 자막에 ‘226개 완벽 지원’이라고 넣지 않는다.

## 참고 앱에서 가져올 만한 확장 방향

| 분야 | 추가 후보 | 현재 딸깍변환과의 차이 |
|---|---|---|
| 사진 입력 | HEIC/HEIF·AVIF·SVG 입력 | 현재 기본 선택 목록에 없음. 디코더·출력 품질 검증 필요 |
| 사진 편집 | 원하는 영역 자르기, 정확한 픽셀·비율 조정, 회전·좌우 반전 | 스캔 자동 보정과 압축 시 크기 조절은 있지만 일반 편집 도구 UI는 없음 |
| 사진 표현 | 밝기·채도·선명도, 화살표·글자·형광펜, 배경·여백·그림자, 콜라주 | 일반 사진 편집과 주석·합성 기능 없음 |
| 개인정보 가리기 | 사진의 수동 영역 모자이크·블러, 얼굴 감지 후 확인 | 전용 도구 없음. 자동 감지 결과는 사람이 확인하는 구조로 제안 |
| 메타데이터 | 사진 GPS·촬영정보, 문서 작성자, 영상·음성 태그 열람·편집·삭제 | 전용 메타데이터 관리 UI 없음. 일부 변환 과정의 정보 손실과 전용 관리 기능은 구분 |
| QR | 이미지 속 QR 내용 읽기 | 별도 디코딩 도구 없음. 참고 기능 확장 아이디어 |
| 영상 편집 | 합치기, 여러 구간·균등 길이 분리, 화면 자르기, 배속, 회전, 특정 프레임 PNG 저장 | 현재 구간 하나를 자르거나 형식을 바꾸는 기능에서 확장 |
| 영상 가리기 | 특정 시간대의 영역 블러·모자이크 | 전용 도구 없음 |
| 음성 편집 | 음량 평준화, 앞뒤 무음 제거, 합치기·다중 분리, 모노·스테레오, 특정 구간 삐 처리 | 현재 형식 변환·단일 구간 자르기에서 확장 |
| 음성 표현 | 정지 사진·파형을 붙인 MP4 만들기 | 전용 도구 없음 |
| PDF 편집 | 썸네일을 끌어 순서 변경, 쪽별 회전·복제·삭제 | 현재는 페이지 번호 입력으로 선택·순서를 정함. 시각 편집 UI 확장 가능 |
| PDF 보호·인쇄 | 암호 설정·정당한 암호 입력 후 해제, 워터마크·쪽번호, 용지 크기·인쇄용 해상도 | 신규 제안. 현재 구현 완료 기능으로 홍보하지 않음 |
| 문서·전자책 | Markdown/HTML/EPUB 변환, CSV↔TSV, ODS 입력 | 현재 기본 변환 목록 밖의 신규 제안. 서식 재현 범위 명시 필요 |
| 자막 | SRT↔VTT, 자막→TXT, 영상에 자막 입히기 | 현재 입력 목록에 자막 형식 없음 |
| 압축 파일 | ZIP/TAR/GZIP 생성·풀기, 지원 가능한 추가 압축 형식 입력 | 현재 압축은 파일 용량 줄이기이며 압축 파일 생성·해제와 다름 |
| 반복 작업 | 폴더 일괄 처리, 작업 대기열·취소·재시도, 결과 이름 규칙, 설정 묶음 | 여러 파일 변환·즐겨찾기에서 확장할 사용성 후보 |
| 빠른 동작 | 경로 복사·폴더 열기·이름 바꾸기·파일 이동 | 변환과 별도로 두는 후보. 참고 앱의 Mac 전용 AirDrop은 Windows 기능으로 그대로 이식하지 않음 |

앞부분의 사진·영상·음성 편집과 메타데이터는 Tangerine 공식 도구 페이지에서 확인했다. QR·PDF 보호·인쇄·반복 작업은 딸깍변환에 대한 추가 제안이며 참고 영상의 기능이라고 단정하지 않는다. 형식 확장은 공식 지원 형식표를 참고했다.

## 제안 우선순위

### 먼저 검토할 묶음

1. **사진 실무**: HEIC→JPG/PNG, 크기·비율·자르기·회전, 수동 모자이크, GPS 정보 삭제, QR 읽기.
2. **영상·음성 실무**: 영상 합치기·여러 구간 분리·프레임 추출, 배속·화면 비율, 음량 평준화·무음 제거.
3. **문서 실무**: PDF 썸네일 편집, CSV/TSV, 자막 SRT/VTT, ZIP 생성·풀기.

### 그다음 검토할 묶음

- 사진 주석·콜라주·배경 제거, 영상 영역 가리기, 파형 영상, 전자책 변환, 음성 인식 등. 모델이나 추가 엔진이 필요한 기능은 설치파일 크기·실행 시간과 지원 아키텍처부터 확인한다.

원형 메뉴는 **변환 / 편집 도구 / 빠른 작업**으로 나누고, 각 원 안에서 자주 쓰는 항목과 즐겨찾기를 앞에 두는 구조를 제안한다. 기존 기본 단축키 F12는 유지한다.

## 릴스 기획에 반영할 점

기존 36초 초안은 대표 장면만 고른 구성이었다. 실제 앱에 이미 있는 **영상→GIF·음성 추출, 사진→문서, 문서 속 사진 추출, OCR**까지 확인되므로 ‘한글을 PNG로 바꾸는 프로그램’으로만 보이지 않게 도입과 캡션의 범위를 넓힐 수 있다.

추가 기능 후보는 구현·실제 시연 전까지 완성 영상에 등장시키지 않는다. 기능 확장을 먼저 할지, 현재 기능으로 릴스 기획을 보강할지는 아직 확정하지 않았다. 영상 제작 승인은 이전과 같이 미확정이다.

# 딸깍변환 3.2.0

파일 선택 → **F12** → 마우스로 클릭. 평소에는 Windows 트레이에서 조용히 대기합니다.

made by [문수네집](https://moonsunezip.com) · [Instagram](https://www.instagram.com/moonsune.zip/)

## 설치와 사용

[**Windows 설치파일 다운로드**](https://github.com/moonsugugu/ddalkkak-converter/releases/download/v3.2.0/DdalKkak-Setup-3.2.0.exe) · [릴리스와 SHA-256](https://github.com/moonsugugu/ddalkkak-converter/releases/latest)

Windows 10/11 **64비트**에서 설치파일을 실행하세요. 바탕 화면·시작 메뉴 바로가기와 Windows 앱 제거 목록에 등록합니다. 기존 문서큐는 새 설치파일을 한 번 실행하면 딸깍변환으로 전환됩니다. 단축키·품질 설정은 보존합니다. 설치본은 FFmpeg/ffprobe를 포함하므로 별도 설치가 필요 없습니다.

1. 바탕 화면 또는 탐색기에서 파일을 선택합니다. 여러 파일도 가능합니다.
2. F12를 누르면 마우스 주변에 클레이 느낌의 원형 메뉴가 뜹니다.
3. 원하는 형식을 클릭합니다. 휠·좌우 버튼·키보드 좌우 키로 다음 원을 넘깁니다. Esc 또는 바깥 클릭으로 닫습니다.
4. **전후 미리보기**에서 원본·변환 결과의 화면, 파일 크기, 이미지 크기와 페이지를 확인합니다. **이대로 저장**을 누르면 결과 폴더가 만들어집니다. **저장 안 함** 또는 창 닫기는 임시 결과를 지웁니다.
5. 결과는 원본 옆 `파일명_변환` 폴더에 저장합니다. 겹치면 `_2`, `_3`을 붙입니다. 원본은 덮어쓰지 않습니다.

기본 순서는 PDF·PNG·용량 줄이기 등을 앞에 두고, 확장자별 사용 횟수를 반영합니다. 즐겨찾기는 가장 먼저 표시합니다. 형식 버튼은 1~8 숫자키로도 고를 수 있습니다. 파일 이름 바꾸기·검색창·다른 앱에서는 F12 입력에 개입하지 않습니다.

## 첫 실행 튜토리얼과 단축키

처음 실행하면 사용 순서와 단축키 설정 팝업이 뜹니다. 시작하기 또는 닫기로 안내를 마치면 다음 실행부터는 트레이에서 대기합니다. 트레이 → **튜토리얼 다시 보기**로 언제든 다시 볼 수 있습니다.

기본 단축키는 **F12**입니다. 트레이 우클릭 → **단축키 변경…**에서 F1~F24, 영문 A~Z, 숫자, Space·Insert·Home·End·PageUp·PageDown 등에 Ctrl·Alt·Shift를 조합하거나 **직접 키를 눌러 지정**할 수 있습니다. 튜토리얼에서도 같은 설정을 지원합니다. **F12로 초기화**하면 기본값으로 돌아갑니다.

단축키는 바탕 화면·탐색기 파일 목록에서만 동작합니다. 이름 입력·검색·다른 앱에서는 해당 키를 유지합니다. 사용자 지정 단일 키는 파일 목록에서 그 키의 기존 동작을 대신합니다. 복사·붙여넣기·창 닫기 등 기본 편집 조합 일부와 Windows 키 조합은 설정 대상에서 제외합니다.

## 전후 미리보기

미리보기는 기본으로 켜져 있으며 트레이 → **변환 후 미리보기**에서 끌 수 있습니다. 끄면 이전처럼 바로 새 결과 폴더에 저장합니다.

사진·PDF는 실제 내용을 표시하며 한글·Office 문서는 설치된 해당 프로그램으로 화면용 PDF를 생성합니다. 여러 원본·결과 파일과 각 페이지를 선택해 비교할 수 있습니다. 문서 프로그램이 없거나 화면으로 표시할 수 없는 영상·음성 등의 형식은 파일 이름·용량으로 확인합니다. 미리보기를 지원하지 않는 형식을 실제 화면으로 표시했다고 안내하지 않습니다.

저장 전 결과는 원본 옆의 표시되지 않는 전용 임시 폴더에 보관하며 저장할 때만 공개 결과 폴더로 옮깁니다. 취소·정상 종료 시 임시 결과를 정리합니다. 미리보기 확인 중에는 설치·제거를 시작하지 않습니다.

## 변환과 도구

### 3.2 사진·PDF 편집과 추가 형식

- **HEIC/HEIF·AVIF·SVG 입력**: PNG/JPG/WebP/AVIF·PDF 등으로 변환합니다. HEIC은 대표 사진 한 장을 읽으며 포함된 FFmpeg를 사용합니다. SVG는 이미지가 포함된 단독 파일만 지원하고 외부 파일·스크립트·스타일을 불러오지 않습니다. 사진은 최대 4천만 화소입니다.
- **사진 편집 / 가리기 / 글자·화살표**: 사진 위를 드래그해 자르기·모자이크·블러·색으로 덮기·화살표·글자·형광펜을 적용합니다. 1:1·4:3·16:9 등의 자르기 비율, 폭·높이, 90도 회전·좌우 반전, 밝기·대비·채도·선명도, 여백·모서리·배경색을 지정하고 전후 미리보기에서 저장합니다. 크기는 한쪽만 입력하면 비율을 유지합니다.
- **콜라주**: 사진 2~100장을 함께 선택하고 F12 → 콜라주에서 열 수·한 칸 크기·간격·배경색을 지정합니다.
- **사진정보 삭제**: 원본의 EXIF·GPS·XMP·썸네일을 새 사진에 복사하지 않습니다. 편집 출력에도 동일하게 적용합니다. 원본 EXIF 보고서는 직접 선택했을 때만 별도 저장하며 위치 정보가 포함될 수 있습니다.
- **PDF 페이지 편집**: 썸네일을 드래그하거나 위/아래 버튼으로 순서를 바꾸고, 회전·복제·삭제합니다. 워터마크·쪽번호도 함께 넣을 수 있습니다. 한 파일씩, 최대 10,000쪽을 편집합니다. 페이지 중심의 사본을 만들며 문서 수준 북마크·고급 기능을 그대로 재현하는 기능은 아닙니다.
- **PDF 암호**: `encrypt`로 AES-256 열기 암호를 설정하고 `decrypt`로 올바른 기존 암호를 입력해 해제한 사본을 만듭니다. 암호는 즐겨찾기에 저장하지 않습니다. 미리보기용으로 해독한 임시 PDF는 저장·취소 시 제거합니다.
- **워터마크·쪽번호**: 문구·쪽번호와 PDF 작성자 등 메타데이터 제거를 지정합니다. 서명된 PDF의 원본 서명을 유지하는 편집은 지원하지 않습니다.
- **Markdown·HTML·EPUB**: TXT/DOCX/PDF의 글자를 Markdown·HTML·EPUB으로 내보내고, Markdown/HTML/EPUB을 PDF·Word·TXT 등으로 바꿉니다. 글자 중심이며 기존 그림·페이지 배치·스타일·링크는 그대로 재현하지 않습니다. HTML에는 실행 코드나 외부 이미지를 넣지 않습니다.
- **CSV·TSV·ODS**: 첫 번째 시트의 값을 CSV/TSV/TXT/XLSX/ODS로 교환합니다. 서식·차트·수식 계산을 재현하지 않으며 새 XLSX에는 수식을 실행하는 대신 글자로 보존합니다.
- **SRT·VTT**: 자막의 시간과 문구를 SRT↔VTT로 바꾸거나 TXT로 꺼냅니다. 영상 음성을 인식해 자막을 만드는 기능은 아닙니다.
- **ZIP·TAR·GZIP**: 선택한 파일을 묶거나 새 결과 폴더에 풉니다. GZIP 생성은 파일 한 개만 지원합니다. 해제는 최대 10,000개·512MB이며 외부 경로·링크·중복 이름을 차단합니다. 암호화 압축파일·RAR/7z는 지원하지 않습니다.

새 기능도 원본 선택 → F12 → 원하는 항목 → 전후 미리보기 → 저장 순서로 사용합니다. 편집 화면과 미리보기를 확인하는 동안 설치·제거가 시작되지 않도록 보호합니다.

| 파일 | 주요 기능 |
|---|---|
| 한글 HWP/HWPX | PDF, PNG/JPG, Word, HWP/HWPX, Excel 표, PPT 페이지 이미지, TXT, 문서 속 사진 압축·추출 |
| Word·Excel·PPT | PDF·페이지 이미지·텍스트 등 형식별 변환. DOCX/PPTX의 사진 압축·추출 |
| 사진 | PNG/JPG/WebP/BMP/TIFF/ICO/PDF/Word/PPT, 용량 줄이기 |
| PDF | Word·Excel·PPT·PNG/JPG·TXT, 사진 압축·추출 |
| 영상 MP4/MOV/MKV/AVI/WebM/M4V | MP4/WebM/MOV/MKV/GIF/MP3/WAV, 용량 줄이기 |
| 음성 MP3/WAV/M4A/AAC/FLAC/OGG | MP3/WAV/M4A/FLAC/OGG |

- **스캔 보정**: 인쇄 문서 사진의 기울기(약 ±10°), 조명·명암, 흰 여백을 정리합니다. 컬러·회색·흑백과 PNG·JPG·PDF를 선택할 수 있습니다. 자동 기울기·여백 정리는 각각 끌 수 있습니다. 보정 결과를 미리보기로 확인한 뒤 저장하세요.
- **PDF 분리**: 한 파일당 쪽수를 지정합니다. 1이면 한 장씩, 5이면 다섯 쪽씩 나누며 마지막 묶음은 더 적을 수 있습니다. 페이지 순서·텍스트를 유지하고 이름에 쪽 번호를 붙입니다. 원본을 덮어쓰지 않습니다.
- **목표 용량**: 파일당 최대 MB 지정. 사진은 크기·품질이 줄어들 수 있습니다. 문서의 사진은 품질을 조절하며 글자·배치를 유지합니다. 목표를 달성할 수 없는 파일은 실제 결과와 함께 미달성으로 알립니다.
- **PDF 합치기**: 사진·한글·PDF·지원 Office 문서를 함께 선택해 하나로 합칩니다. 목록의 위/아래 버튼으로 순서를 정합니다. 원본이 여러 폴더에 있으면 첫 번째 원본 옆에 저장합니다.
- **페이지 선택**: 남길 페이지를 `1,3-5,2`처럼 순서대로 입력합니다. `5-1`은 역순이며, 입력하지 않은 쪽은 결과에서 제외합니다. PDF·PNG·JPG·Word·TXT·PPT·Excel로 저장할 수 있습니다.
- **글자 → TXT / Word**: 인쇄 문서 사진·스캔 PDF를 Windows OCR로 읽습니다. 한국어 OCR이 설치되어 있으면 한국어로 인식합니다. 미설치 시 Windows 설정 → 언어 → 한국어 → 광학 문자 인식을 설치하라는 안내가 나옵니다. 표·배치는 재현하지 않으며 인식 결과를 확인해야 합니다.
- **구간 자르기**: 시작·끝 시간을 초 또는 `00:01:30`으로 지정해 GIF·영상·음성으로 저장합니다. 끝을 비우면 마지막까지 변환합니다.
- **즐겨찾기**: 고급 도구에서 이름을 입력하면 형식·품질·목표 MB 등의 설정이 저장됩니다. 일반 변환은 원형 메뉴의 **설정 저장**에서 등록합니다. 트레이 → 설정에서 삭제합니다.

네이티브 한글·Office 문서를 여는 변환에는 해당 프로그램이 필요합니다. HWP 자동화는 기존에 열려 있는 문서를 종료하지 않고, 변환용 사본만 열고 닫습니다. PDF → Word는 텍스트 중심, PDF → PPT는 페이지 이미지입니다. MP4 영상·음성 변환용 FFmpeg/ffprobe는 설치본에 포함합니다.

## 트레이와 설치 수명 주기

트레이 우클릭: 열기, 설정, 업데이트 확인, 사용 방법, 단축키 직접 지정·빠른 선택, 미리보기, 튜토리얼, 품질, Windows 자동 실행, 최근 결과, 오류, 현재 영상·음성 중지, 종료.

- 같은 버전 설치파일: 다시 설치/복구 또는 제거. 이전 버전: 업데이트 또는 제거. 더 오래된 설치파일로 최신 설치를 덮어쓰지 못합니다.
- 제어판·Windows 설정의 앱 목록, 시작 메뉴의 제거 바로가기, 앱 설정의 **앱 제거**에서 표준 제거 프로그램을 실행합니다.
- 제거 시 이 앱의 실행파일·바로가기·자동 실행·등록을 정리하고 설정·즐겨찾기·변환 결과는 기본 보존합니다. 설치 폴더에 사용자가 넣은 다른 파일은 삭제하지 않습니다.
- 설정 위치: `%LOCALAPPDATA%/Moonsunezip/DocQ/settings.json`. 이전 문서큐의 저장 위치·프로세스 통신 식별자를 유지해 업그레이드합니다.
- 설치·제거는 현재 변환 중이면 시작하지 않습니다. 다른 한글/Office 프로세스를 강제 종료하지 않습니다.

## 업데이트 배포 상태

앱 시작 12초 후와 6시간마다 조용히 확인하며 트레이·설정의 수동 확인도 제공합니다. SemVer·Windows·아키텍처·정식 채널을 확인하고 HTTPS로 받은 설치파일의 크기와 SHA-256이 일치해야 실행합니다. 네트워크 실패를 최신 버전으로 표시하지 않습니다.

고정 피드: `https://github.com/moonsugugu/ddalkkak-converter/releases/latest/download/latest.json`

공식 배포는 이 저장소의 GitHub Releases와 위 고정 피드를 사용합니다. 현재와 같은 버전이면 최신 버전으로 안내하고, 더 높은 정식 버전이 게시되면 업데이트를 안내합니다. 이전 문서큐에는 업데이트 기능이 없어 이번 설치파일을 한 번 실행해야 합니다. 공개 릴리스에서 구버전의 새 버전 감지부터 설치까지 이어지는 전체 검증은 다음 버전 배포 때 별도로 수행합니다.

공개할 때 `product.py`, `version-info.txt`, 설치파일·릴리스 태그·`latest.json` 버전을 일치시키세요. `build.ps1`이 만든 설치파일과 `SHA256SUMS.txt`를 먼저 릴리스에 올리고, 마지막에 `latest.json`을 올립니다. 공개 피드에는 토큰이 필요하지 않아야 합니다. 설치파일은 현재 코드 서명 인증서로 서명하지 않았습니다.

## 빌드와 검증

Python 3.13 32비트 가상환경(한글 COM 호환), requirements.txt, NSIS 3가 필요합니다. `build.ps1`은 테스트 → 아이콘·HWP 타입 라이브러리 → 앱 EXE → FFmpeg 도구 포함 NSIS 설치파일 → 해시·메타데이터 순서로 만듭니다.

```powershell
py -3.13-32 -m venv --system-site-packages .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest -v
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

빌드 PC에는 한컴오피스 한글과 FFmpeg/ffprobe가 필요합니다. NSIS 컴파일러는 `build.ps1`의 경로를 확인하세요. 사용자별 변환 파일·검증 자료·가상환경·설치파일은 소스 Git에 포함하지 않습니다.

앱 소스는 [AGPL-3.0](LICENSE)으로 공개합니다. PyMuPDF/MuPDF의 AGPL 라이선스를 따르며, 각 외부 구성 요소는 해당 라이선스를 유지합니다. 설치 폴더의 `LICENSES.txt`에는 배포에 포함한 구성 요소의 고지와 라이선스 원문이 있습니다. FFmpeg는 별도 실행파일로 포함합니다. 한글·Microsoft Office는 포함하지 않으며 해당 프로그램의 사용권이 필요합니다. 한글 자동화 모듈의 출처는 [vendor/README.md](vendor/README.md)를 참조하세요.

`FFmpeg-SOURCE.txt`와 포함된 FFmpeg 라이선스를 참조하세요. 코드룰 기준: [설치형 앱 필수 규칙](https://github.com/moonsugugu/coderule/blob/f4e29bead0348631a9bd71625b1e2af2951ad1ba/README.md#9-설치형-앱-아이콘삭제업데이트-필수-규칙).
